**RestAssured API Automation Framework**

[![RestAssured API Test Automation CI](https://github.com/sanishkc/restassured-api-automation-framework/actions/workflows/api-tests.yml/badge.svg)](https://github.com/sanishkc/restassured-api-automation-framework/actions/workflows/api-tests.yml)

**Overview:**

This repository contains a comprehensive API automation framework built using RestAssured (Java).
It automates authentication and user management APIs, demonstrating GET, POST, and PUT operations, while following enterprise best practices such as:

 - Builder-based request/response models
 - Service layer abstraction
 - Custom logging filters
 - TestNG listeners
 - CI/CD readiness

**Tech Stack:**

 - RestAssured – API automation  
 - Java 
 - Maven – Build & dependency management  
 - TestNG – Test framework  
 - Git & GitHub – Version control  
 - CI/CD Ready – GitHub Actions / Jenkins compatible  

**Test Coverage:**

  Authentication APIs

   - POST /api/auth/login - Validates user login
   - POST /api/auth/signup - Creates a new user with unique email

User Management APIs

  - GET /api/users/profile - Retrieves logged-in user's profile
  - PUT /api/users/profile - Updates user profile details
